## Case study

Greenfield Family Clinic: a simulated Clinic Appointment System. Receptionists book appointments, doctors record diagnoses and prescriptions, and administrators report on workload. All records are fictional. The full description is in the Portfolio 1 README.

## Environment

The work runs in GitHub Codespaces. PostgreSQL 16 holds the database greenfield_clinic_portfolio, and MongoDB holds the clinic_events database. No passwords or credentials are stored in this repository.
